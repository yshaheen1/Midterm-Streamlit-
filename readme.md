## Project Overview

This Streamlit application demonstrates the **core capabilities of the Streamlit library**.  
It simulates **retail store performance** across **ten cities in Massachusetts** over a **six-month period (January–June)**.

The app combines:
1. **Interactive data exploration** (via tables and KPIs)  
2. **Visual analytics** (bar and line charts)  
3. **Geospatial mapping** (store locations across Massachusetts)

---

## Core Capabilities
- Create **interactive dashboards** with sliders, buttons, inputs, and charts  
- Display **dataframes and KPIs** for real-time analysis  
- Visualize data using built-in **line, bar, and scatter charts**  
- Integrate with **Pandas, NumPy, Matplotlib, Plotly, and scikit-learn**  
- Deploy instantly to the **Streamlit Community Cloud**
